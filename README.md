# F1-Race-Performance-Strategy-Analyst-using-Python
This project analyzes real Formula 1 race telemetry and timing data using FastF1, Pandas, Matplotlib, and Seaborn.  The project performs: - Driver performance analysis - Tyre strategy analysis - Stint analysis - Lap consistency analysis - Tyre degradation tracking - Weather analysis - Race pace visualization
---

## Technologies Used

- Python
- FastF1
- Pandas
- Matplotlib
- Seaborn

---

## Features

### Driver Performance Analysis
- Average lap times
- Fastest laps
- Slowest laps
- Total laps completed

### Tyre Strategy Analysis
- Tyre compound usage
- Stint duration
- Pit-stop estimation

### Consistency Analysis
- Standard deviation
- Coefficient of variation
- Pace stability

### Tyre Degradation Analysis
- Lap-time increase within stints
- Tyre wear tracking

### Weather Analysis
- Air temperature
- Track temperature

## Sample Visualizations

- Lap time evolution graph
